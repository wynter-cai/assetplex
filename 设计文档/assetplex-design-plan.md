## 一、Summary 概要

**目标**：构建一个开源 CLI 工具 `agenthub`，集中管理跨多个 AI 编程工具的：
1. **个人身份设定**（profile.md + AI 自动维护的 profile.auto.md）
2. **Skills 技能库**（SKILL.md 标准，跨工具同步）
3. **个人偏好文件**（编码风格、Git 工作流、工具快捷键）
4. **MCP 服务器配置**（JSON↔TOML 自动转换）
5. **通用规则与命令**（AGENTS.md 标准 + 自定义 slash commands）

**核心差异化**：
- 唯一原生支持中国工具栈（TRAE CN / WorkBuddy / Qoder）的 Hub
- 唯一引入"AI 自动维护个人画像"层（扩展 TRAE 已有的 `user_profile.md` 模式）
- 唯一集成 Skill 市场发现（聚合 claudeskills.info / agentskills.io / agskills.dev）

**预期开源价值**：填补 6+ 个海外竞品（agentsync / agentsmesh / sync-rules / sync-coding-agents / ruler / rulesync）在中国工具栈和身份画像层的空白。

## 四、同步策略：分层混合

### Layer 1: 原生 @import（仅 Claude Code，最优）

生成 `~/.claude/CLAUDE.md` 内容：
```markdown
<!-- AUTO-GENERATED by assetplex. Do not edit directly. Run `assetplex sync` to update. -->
@~/.assetplex/identity/profile.md
@~/.assetplex/identity/profile.auto.md
@~/.assetplex/identity/communication-style.md
@~/.assetplex/identity/tech-stack.md
@~/.assetplex/preferences/coding-style.md
@~/.assetplex/preferences/git-workflow.md
@~/.assetplex/rules/always/global.md
```

### Layer 2: 符号链接（默认）

- `~/.assetplex/skills/<name>` → `~/.claude/skills/<name>`
- `~/.assetplex/skills/<name>` → `~/.trae-cn/skills/<name>`
- `~/.assetplex/skills/<name>` → `~/.codex/skills/<name>`
- `~/.assetplex/skills/<name>` → `~/.workbuddy/skills/<name>`

**Windows 实现**：
- 优先 `mklink /D`（开发者模式或管理员）
- Fallback：junction `mklink /J`（无需权限）
- 终极 fallback：copy + watch

### Layer 3: 同步脚本兜底（无法软链的场景）

- **Codex 的 TOML**：必须生成（无法软链 JSON → TOML）
- **WorkBuddy 的 `${VAR}` 插值**：需要单独处理
- **Qoder 的项目级 `.qoder/`**：必须按项目分发

### Layer 4: 工具适配器（Plugin 架构，借鉴 agentsmesh）

每个适配器实现统一接口：
```typescript
interface ToolAdapter {
  name: string;
  detect(): Promise<ToolStatus>;        // 检测工具是否安装、版本
  targets(): SyncTarget[];              // 返回同步目标路径列表
  apply(item: HubItem, content: Buffer): Promise<void>;  // 应用 Hub 内容到工具
  import(targetPath: string): Promise<HubItem>;            // 反向导入
  transform(content: Buffer, format: 'json' | 'toml' | 'md'): Buffer;  // 格式转换
  lint?(items: HubItem[]): LintWarning[];                 // 同步前警告
}
```

**5 个内置适配器**：

| 适配器 | 配置目录 | 同步策略 | 特殊处理 |
|---|---|---|---|
| `trae-cn` | `~/.trae-cn/` | symlink | 接管 `memory/user_profile.md`、`skills/`、`rules/`、`mcp.json` |
| `claude-code` | `~/.claude/` + `~/.claude.json` | native-import | 生成 CLAUDE.md 聚合 @import；MCP 写入 `~/.claude.json` |
| `codex` | `~/.codex/` | copy | JSON → TOML 转换；`AGENTS.md` 内容合并 |
| `workbuddy` | `~/.workbuddy/` | symlink | `${VAR}` 环境变量插值；`.mcp.json` 前导点 |
| `qoder` | `<project>/.qoder/` | per-project | 按项目分发；AGENTS.md 兼容 |

## 五、竞品调研结果（6+ 直接竞品）

| 项目 | 形态 | 支持工具 | 亮点 |
|---|---|---|---|
| **agentsync** (Rust) | CLI + symlink | Claude/Codex/Cursor/Copilot/Gemini/OpenCode | 跨平台、Rust 静态二进制、62 版本 |
| **agentsmesh** (TS) | CLI + MCP Server | 同上 + Lessons 共享记忆 | 8000+ 测试、lossless 往返、插件架构 |
| **sync-rules** (Node) | CLI | 5 工具 | glob 选择性同步、per-harness override |
| **sync-coding-agents** | CLI 0 依赖 | Claude+Copilot | 极简、relative symlinks |
| **ruler** | CLI | 多工具 | 老牌 |
| **rulesync** | CLI | 多工具 | 支持 import 回流 |
| **wshobson/agents** | 插件市场 | 5 工具原生消费 | 94 plugins/203 agents/175 skills |

**关键观察**：
1. 所有竞品都聚焦**海外工具栈**，没有一个原生支持 TRAE CN / WorkBuddy / Qoder
2. 所有竞品都做"配置同步"，没有做"AI 自动维护个人画像"
3. 没有竞品集成 Skill 市场发现
4. 同步赛道红海，但中国本土化 + 画像层是明确蓝海

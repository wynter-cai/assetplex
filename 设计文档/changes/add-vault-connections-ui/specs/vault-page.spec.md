# Spec: Vault Page (资产库)

> Capability: vault-page
> 对应页面: `/vault` (资产库)

## ADDED Requirements

### R1: 双栏布局

资产库采用左侧类别导航 + 右侧内容区的双栏布局。

#### Scenario: 标准布局
**Given** 用户进入资产库
**When** 页面加载完成
**Then** 左侧显示类别导航：
  - 👤 身份 (N)
  - ✨ 技能 (N)
  - 📖 规则 (N)
  - 🖥 MCP (N)
**And** 类别旁显示该类别下的资产数量
**And** 右侧显示当前选中类别的资产列表

#### Scenario: 类别数量动态显示
**Given** 用户从"身份"切换到"技能"
**When** 切换发生
**Then** 左侧导航"技能"项高亮
**And** 右侧内容区显示技能类别的资产列表

### R2: 资产卡片展示

资产以卡片形式展示，而非文件列表。

#### Scenario: 资产卡片信息
**Given** Hub 中有一个技能 `skills/react-expert.md`
**When** 用户在资产库查看技能类别
**Then** 显示资产卡片，包含：
  - 资产名称: "react-expert"
  - 类别图标: ✨
  - 来源标签: "来源: TRAE" 或 "来源: 手动创建"
  - 最后修改时间: "今天" / "3天前" / "2026-08-10"
  - 分发状态条: 显示该资产同步到哪些工具（彩色圆点）
  - 操作按钮: [查看] [编辑] [分发管理]

#### Scenario: 资产无分发
**Given** Hub 中有一个新建的规则，还未同步到任何工具
**When** 用户查看该规则卡片
**Then** 分发状态条显示"未分发"
**And** 操作按钮中的"分发管理"高亮提示

### R3: 资产搜索和筛选

#### Scenario: 按关键字搜索
**Given** 用户在资产库查看技能类别
**When** 用户在搜索框输入"react"
**Then** 资产列表实时过滤，只显示名称或内容包含"react"的资产
**And** 如果没有匹配结果，显示空状态"未找到匹配 'react' 的技能"

#### Scenario: 无搜索结果
**Given** 用户搜索"nonexistent"
**When** 没有匹配的资产
**Then** 显示空状态："未找到匹配的资产"
**And** 提供"清除搜索"按钮

### R4: 资产新建

#### Scenario: 创建新资产
**Given** 用户在资产库的技能类别
**When** 用户点击右上角"+ 新建"按钮
**Then** 右侧切换到资产编辑器
**And** 编辑器显示空白的 Markdown 编辑区
**And** 顶部有"名称"输入框和"保存"按钮

#### Scenario: 保存新建资产
**Given** 用户在编辑器中输入了名称和内容
**When** 用户点击"保存"
**Then** 资产保存到 Hub
**And** 返回资产列表，新资产显示在列表顶部
**And** 显示成功提示"已创建技能: [名称]"

### R5: 资产查看和编辑

#### Scenario: 查看资产详情
**Given** 资产列表中有一个资产卡片
**When** 用户点击"查看"按钮
**Then** 右侧切换到资产查看器
**And** 显示资产的 Markdown 内容（只读模式）
**And** 底部显示"分发到哪些工具"的列表

#### Scenario: 编辑资产
**Given** 用户在查看资产详情
**When** 用户点击"编辑"按钮
**Then** 切换到编辑模式，Markdown 内容可编辑
**And** 顶部显示"保存"和"取消"按钮

### R6: 分发管理

#### Scenario: 打开分发管理
**Given** 用户在资产卡片上
**When** 用户点击"分发管理"按钮
**Then** 弹出分发管理对话框
**And** 对话框显示所有已安装工具的列表
**And** 每个工具旁有一个开关，表示是否启用同步
**And** 显示当前同步状态（已同步/待更新/未启用）

#### Scenario: 切换分发开关
**Given** 用户在分发管理对话框
**When** 用户开启"WorkBuddy"的同步开关
**Then** 该资产被标记为"待同步到 WorkBuddy"
**And** 对话框底部显示"立即同步"按钮
**And** 点击"立即同步"启动同步流程

### R7: 导入入口

#### Scenario: 从资产库发起导入
**Given** 用户在资产库
**When** 用户点击右上角"⬇ 导入"按钮
**Then** 启动入库向导（Step 1: 扫描工具）
**And** 入库向导完成后，自动刷新资产列表

### R8: 空状态

#### Scenario: 某类别无资产
**Given** 用户切换到 MCP 类别，但 Hub 中没有 MCP 资产
**When** 页面加载完成
**Then** 右侧显示空状态：
  - 图标 🖥
  - 标题"还没有 MCP 资产"
  - 描述"扫描已安装的工具，把 MCP 配置导入到 Hub"
  - 按钮"立即导入"

### R9: 资产类别动态扩展

#### Scenario: 支持新增资产类别
**Given** 未来 Phase B 新增了 `command` 类别
**When** 配置中添加了 `command` 类别定义（图标、显示名）
**Then** 资产库左侧导航自动显示"⚡ 命令 (N)"项
**And** 无需修改前端代码（类别从配置读取）

# Proposal: add-skill-curation

> 级别：M | 日期：2026-10-06 | 状态：待审核

## Goal

第三方技能（市场/内置/插件/个人目录里的 airbnb 等）随时可重装，不是核心资产；保险箱里的自建技能才是。本变更补上「沉淀到保险箱」工作流：把用着好的第三方技能一键复制进保险箱，记录来源，使其成为可编辑、可分发、可长期演进的自己的资产。

## Scope

**做**：
1. 单条沉淀：详情面板对非保险箱技能提供「沉淀到保险箱」动作，复制 SKILL.md 内容创建保险箱副本，记录来源
2. 批量沉淀：复用现有勾选批量条，批量沉淀多个第三方技能，同名冲突跳过并报告
3. 来源标识：保险箱技能记录来源（自建 / 沉淀自某来源），详情面板可见，编辑后保留

**不做**：
- AI 自动分类（下一变更 add-skill-ai-classification）
- 联网检测第三方技能更新、技能市场/安装功能
- 智能体的沉淀动作（智能体已有 hub 写管理，本轮范围控制）
- 沉淀时编辑描述/正文（沉淀后用现有编辑功能改）

## Risks

- frontmatter 额外字段（source）的解析兼容性——实施第一个任务先验证解析器容忍未知键，不行则改用注释行方案
- 沉淀后源技能与保险箱副本同名，盘点去重会合并为一张卡（保险箱优先）——预期行为，spec 中明确
- 批量沉淀部分失败（同名冲突）——设计为跳过并报告，不整批回滚

# spec: 技能出处分类重构（refactor-skill-origin-taxonomy）

> 术语基线：**我的库**（原保险箱）、**收藏**（原沉淀）、**自建**（原个人自建+项目技能+库内自建合并的纯出处）

## MODIFIED Requirements

### Requirement: 出处轴为纯出处四类（MECE）

技能列表「按来源」 chips 只表达**纯出处**（这个技能最初从哪来），四类互斥且完全穷尽：

| chip | 定义（判定规则） | 当前计数 |
|------|----------------|---------|
| 自建 | 库内自建(31) + 项目技能(68) | 99 |
| 市场安装 | 从技能市场安装（含库内沉淀自市场的） | 292 |
| 插件自带 | 随插件分发 | 27 |
| 官方内置 | 工具官方出厂 | 24 |

#### Scenario: 四类互斥计数
- Given 技能总数 442（2026-10-06 基线）
- When 打开技能页
- Then chips 行显示：自建 99 / 市场安装 292 / 插件自带 27 / 官方内置 24，四类计数之和 = 442
- And 不存在「保险箱」「个人自建」「项目技能」字样的 chip

#### Scenario: 沉淀技能的出处归属
- Given 一个市场安装技能已被收藏进我的库（源文件保留在市场目录）
- When 查看它的出处 chip 计数
- Then 它计入「市场安装 292」，不重复出现在「自建」（同一技能只有一个出处）

### Requirement: 库状态与出处正交（状态开关独立表达）

「是否已入我的库」是管理状态，不占出处分类轴；用三档分段控件表达：**全部 / 我的库 / 未入库**，可与出处 chips 组合。

#### Scenario: 待收藏候选（杀手级交集查询）
- Given 市场安装技能 292 个、其中已收藏 0 个
- When 用户选择状态「未入库」并点击 chip「市场安装」
- Then 列表显示 292 个未入库的市场技能（待收藏候选清单）

#### Scenario: 我的库视图
- Given 我的库现有 31 个技能（全部自建）
- When 用户选择状态「我的库」
- Then 列表只显示这 31 个，出处 chips 计数联动重算（自建 31 / 市场安装 0 / 插件自带 0 / 官方内置 0）

#### Scenario: 全部（默认）
- When 打开技能页
- Then 状态默认「全部」，出处 chips 计数为全集构成（99/292/27/24）

### Requirement: 术语对陌生用户开箱即用

UI 全部文案不出现「保险箱」「沉淀」「个人自建」「项目技能」（作为分类名）；统一替换：

| 原 | 新 |
|----|----|
| 保险箱 | 我的库 |
| 沉淀到保险箱 | 收藏到我的库 |
| 沉淀自 市场 | 来自 市场 |
| 批量「沉淀到保险箱」 | 批量「收藏到我的库」 |
| 删除确认「将从保险箱及所有已分发工具中删除」 | 「将从我的库及所有已分发工具中删除」 |
| agent 标签「保险箱」 | 「我的库」 |

#### Scenario: 陌生用户走查无圈内黑话
- When 以未使用过本产品的用户视角浏览技能页、详情面板、收藏对话框、批量操作条、确认弹窗
- Then 全部界面文案不含「保险箱」「沉淀」字样

#### Scenario: 详情面板来源徽章
- Given 一个收藏自市场的库内技能
- When 打开详情
- Then 徽章显示「来自 市场」（不再是「沉淀自 市场」）

### Requirement: 写管理契约等价迁移（行为不变）

写接口（创建/编辑/删除/同步分发）仅作用于库内技能的契约语义等价迁移：原 `origin=vault` 判定 → `inLibrary=true`，状态码与错误体不变。

#### Scenario: 非库技能只读 + 收藏入口
- Given 一个市场安装且未入库的技能
- When 打开详情
- Then 不显示编辑/删除按钮，显示「收藏到我的库」按钮

#### Scenario: 库内技能可写
- Given 我的库中一个技能
- When 打开详情
- Then 显示编辑/删除/同步分发按钮

#### Scenario: 收藏行为不变（只改文案）
- Given 一个未入库技能，用户在收藏对话框确认
- When 提交
- Then 复制到库目录 + frontmatter 记录来源溯源 + 源技能保留不动（与原沉淀行为逐字节等价）

### Requirement: 内部标识与数据零迁移

磁盘 vault 目录名、source frontmatter 格式（`origin:path`）、AI 分类缓存（内容 hash key）全部不动；仅 API 对外语义与 UI 层重构。

#### Scenario: 换皮不重扫
- When 重构上线
- Then 不触发重新扫描、不触发 AI 重新分类、不产生数据迁移脚本；442 个技能的 AI 分类缓存全部命中

## 边界与不做

- 职能九类（编码开发/浏览器自动化/工作流自动化…）同样混维度（渠道/模式混进领域轴），**本次不做**，下一步单独议
- vault 物理目录、内部 origin 枚举值不重命名（避免数据迁移），只改对外语义与 UI

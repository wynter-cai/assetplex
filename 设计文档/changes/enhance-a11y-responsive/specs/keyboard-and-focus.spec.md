# spec: keyboard-and-focus（键盘可达与焦点可见）

> capability：纯键盘用户可以不借助鼠标完成导航、筛选、打开详情、关闭浮层
> 关联：proposal G1/G2/G5/G6、D1/D2/D4/D5/D7
> 消费者：AppLayout、Sidebar、所有页面与浮层

## 为什么需要这份 spec

当前只有 `ui/` 里的五个原语（button / input / switch / tabs / textarea）带焦点环，侧栏链接、卡片里的文字按钮、toast 的「查看详情」都是「焦点在哪看不出来」。再加上每个页面开头必须先穿过 16 个导航元素，纯键盘用户实际上用不了这个产品。本 spec 定义可验收的键盘行为。

## Scenario 1 — 跳过导航

- **Given** 打开的页面是资产库
- **When** 按下第一次 `Tab`
- **Then** 页面顶部出现一个可见的「跳到主内容」按钮，位于视口内
- **And** 再按 `Enter` 后焦点落在主内容区，侧栏所有导航项被跳过
- **And** 焦点离开该按钮后它重新隐藏（不占据布局空间）
- **And** 未按 Tab 时该按钮不可见，且不遮挡任何内容

## Scenario 2 — 焦点随处可见

- **Given** 任一页面
- **When** 连续按 `Tab` 遍历
- **Then** 每个获得焦点的元素都有 ≥2px 的可见焦点环，且环与背景的对比度 ≥3:1
- **And** 侧栏主导航项、侧栏类别子项、卡片标题按钮、文本型链接按钮（如 toast「查看详情」）都包含在内
- **And** 焦点环不引起布局抖动（不改变元素尺寸与相邻位置）

## Scenario 3 — 侧栏折叠按钮语义正确

- **Given** 桌面宽度下的侧栏
- **When** 用 Tab 移到「资产库」右侧的折叠按钮
- **Then** 该按钮有可读名称（「收起资产库」/「展开资产库」）与 `aria-expanded` 状态
- **And** 折叠按钮不在「资产库」链接的可点击区域内部（两者是并列的可聚焦元素，不是嵌套）
- **And** 按 `Enter` 折叠后，类别子项从 Tab 序列中消失

## Scenario 4 — 窄屏抽屉键盘可操作

- **Given** 视口宽度 375px
- **When** 按 Tab 到汉堡按钮并按 `Enter`
- **Then** 侧栏抽屉打开，焦点自动落到第一个导航项
- **And** `aria-expanded="true"`，抽屉带 `aria-label`
- **And** 在抽屉内连续按 `Tab` 不会跑到抽屉背后的内容（循环回到抽屉第一个可聚焦元素）
- **And** 按 `Esc` 关闭抽屉，焦点回到汉堡按钮

## Scenario 5 — 浮层关闭后焦点归还

- **Given** 已打开资产详情或任一对话框
- **When** 按 `Esc` 关闭
- **Then** 焦点回到触发它的那个元素
- **And** 不落到 `document.body`（不丢失键盘位置）

## Scenario 6 — 领域语义清晰

- **Given** 任一页面
- **When** 用屏幕阅读器按地标跳转
- **Then** 能听到三个命名地标：侧边栏、主导航、主内容
- **And** 页内只有 1 个 H1
- **And** 不存在 `<button>` 嵌套在 `<a>` 内的结构

## Scenario 7 — 尊重减少动效

- **Given** 操作系统开启了「减少动效」
- **When** 打开抽屉、触发展示级 toast、切换选项卡
- **Then** 过渡与滑入动画基本不播放（时长被压到近乎 0）
- **And** 状态变化照旧发生（抽屉打开、toast 出现并按时消失）
- **And** 未开启该偏好时动画保持现状

## Scenario 8 — 筛选结果变化有播报（拍板点 C，默认纳入）

- **Given** 资产库列表中有 120 项
- **When** 在筛选栏选择「记忆」类别
- **Then** 结果数变化的文本区域带 `role="status"`，屏幕阅读器播报新的条目数
- **And** 播报不打断当前焦点

## 验收口径

- Playwright 用例覆盖 Scenario 1 / 3 / 4 / 5 的 `document.activeElement` 断言；
- RTL 用例覆盖 Scenario 3 的 `aria-expanded` 与「无嵌套按钮」结构断言；
- 焦点环覆盖：`grep` 断言侧栏与卡片类组件不再依赖组件内 ring（允许保留，但必须全局兜底生效）；
- 动效偏好无自动化手段时，人工在系统设置里切换一次并截图对比（截图不入库）。

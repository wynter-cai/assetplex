# Spec: 术语统一

> Capability: terminology
> Change: refactor-design-system（P1-6）
> 背景实测：同一概念多个叫法——库内资产叫"我的库/保险箱/Hub/AssetPlex"；
> 入库动作叫"收藏/沉淀到保险箱/导入"；分发叫"同步/分发同步/已同步"；
> 出处轴一边叫分组「自建」一边叫徽章「项目 · Super Powers」；
> 设置页标题「Hub 设置」副标题甩实现文件 hub.toml。
> 路线图已定调：「我的库 / 收藏 / 同步」三个词定终身。

## MODIFIED Requirements

### Requirement: 核心词汇定终身

全站用户可见文案中，以下概念各只有一个词：

| 概念 | 唯一词 | 禁用别称 |
|---|---|---|
| 库内资产（Hub 中的资产集合） | 我的库 | 保险箱、Hub、AssetPlex（指代资产集合时） |
| 入库动作（把外部/工具资产收进我的库） | 收藏 | 沉淀到保险箱 |
| 分发（把我的库资产分发到各 AI 工具） | 同步 | 分发同步 |

#### Scenario: 库内资产的指代

- **Given** 用户浏览首页快照、资产库、技能卡徽章等指代"库内资产"的位置
- **When** 查看文案
- **Then** 一律呈现「我的库」，不出现以"保险箱/Hub/AssetPlex"指代资产集合的文案

#### Scenario: 入库动作

- **Given** 用户在技能详情/批量操作/导入流程中使用入库功能
- **When** 查看按钮与结果文案
- **Then** 动作一律称「收藏」（如「收藏到我的库」），不出现「沉淀到保险箱」

#### Scenario: 分发动作

- **Given** 用户在连接页/同步中心查看分发能力
- **When** 查看文案
- **Then** 一律称「同步」（含状态「已同步」），不出现「分发同步」混称

### Requirement: 出处轴一词

#### Scenario: 自建资产的标识

- **Given** 用户查看资产分组与技能卡出处徽章
- **When** 查看同一出处轴的标识
- **Then** 全站使用同一个词标识该轴（本 spec 提案用「自建」，评审可整体换词，但不允许一词两用）
- **And** 出处徽章格式统一为「轴名 · 来源名」（如「自建 · Super Powers」），不再出现同轴两个名字并存的组合

### Requirement: 设置页说人话

#### Scenario: 打开设置页

- **Given** 用户打开设置页
- **When** 查看标题与副标题
- **Then** 标题为「设置」，副标题用用户语言描述用途（如管理资产存储与 AI 工具连接）
- **And** 不出现「Hub 设置」或 hub.toml 等实现细节措辞（编辑配置文件的高级入口若保留，放入明确的次要位置并自带说明）

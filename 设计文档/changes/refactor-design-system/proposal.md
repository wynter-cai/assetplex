# Proposal: refactor-design-system（设计系统立骨）

> **级别**：M（设计系统 + 信息架构 + 术语，多模块前端改版）
> **日期**：2026-10-08
> **依据**：[assetplex-ui-ux-audit-2026-10-07.md](../../assetplex-ui-ux-audit-2026-10-07.md) P1-1 ~ P1-7
> **路线图位置**：[assetplex-ui-ux-roadmap.md](../../assetplex-ui-ux-roadmap.md) P1 阶段
> **前置**：P0 `fix-ui-trust-gaps` 已完成并本地提交（toast/错误态底座就绪）

## Goal（解决什么问题）

应用功能可用但"两套主色并存、没有字体体系、三级导航两级重复、术语四个词混用"，界面仍像调试台。本变更建立**可演进的设计令牌与排版体系**，让信息架构不再重复、界面在笔记本屏幕上可用、同一概念全站只有一个名字。

**已拍板决策（2026-10-08 维护者评审）**：
1. 品牌主色 = **靛蓝 indigo-600**（近黑 slate-900 primary 退役）
2. 暗色模式 = **暂时摘除**（.dark 令牌与 dark: 类全清，开源后按反馈正式加回）
3. 导航形态 = **撤 Vault 内 192px 类别栏**（类别导航只保留全局侧栏一处）

## Scope（做什么 / 不做什么）

**做**：
1. 品牌色令牌收编：`--primary` 切靛蓝，语义色（成功/警告/危险/信息）入令牌且达 AA，硬编码 `indigo-*` 清零
2. 字体体系：中文栈落定 + 6 档 type scale（12/13/14/16/20/24），10px 中文清零，统计数字等宽
3. 页头统一：标准页头结构（H1 20px + 副标题 + 右侧操作区），资产库各页补页头，30px 页头收敛
4. Markdown 排版层级恢复：H1 18 / H2 16 / H3 14 / 正文 14（行高 ≥1.6）
5. 导航去重：撤 Vault 内类别栏；详情面板 <1024px 改全屏/抽屉；列表卡片不再 <200px；连接页负 margin 出血清理
6. 技能卡徽章减负（基础版）：卡面常驻徽章 ≤2 枚，其余进详情；移除「查看详情」重复入口
7. 术语统一：「我的库 / 收藏 / 同步」定终身，出处轴一词；词汇表沉淀进资产分类法文档
8. 暗色模式代码摘除

**不做**（防蔓延）：
- 侧栏折叠/汉堡菜单、完整断点体系、焦点可见/skip-link/aria（P2-A `enhance-a11y-responsive`）
- 技能卡色彩编码图例、行内 select 确认式改造（P2-B `refine-skill-cards-wizard`）
- 活动、健康度解释、计数口径（P2-C `add-activity-feed-data-semantics`）
- 视觉 elevation 体系、原生控件混搭统一（P2-5/P2-8，随 P2-A 顺手消化）
- 暗色模式重设计（只摘除不重做）
- 职能九分类 MECE 重构（P2-9 独立议题）
- **零后端 API 契约变更**（纯前端展示层，后端字段值不动）

## Risks（风险点）

| 风险 | 缓解 |
|---|---|
| primary 换靛蓝后 Logo/favicon/侧栏选中态观感突变 | favicon 与侧栏选中态走 `--primary` 令牌自动跟随，同步换靛蓝；浏览器逐页回环核对 |
| 语义色改软底深字后，依赖原色类名的测试断言失败 | 组件测试断言行为与文本而非像素色；先改测试夹具再改样式 |
| 撤类别栏后「当前在哪个类别」线索只剩侧栏 | 资产库各页补 H1 页头（类别名），双保险（spec 有对应场景） |
| 详情抽屉化改动 Vault 主从布局，改动面大 | 组件测试先行；≥1024px 保留主从（仅保卡片最小宽），<1024px 才 overlay |
| 摘 dark 后 shadcn 组件若隐式依赖 dark 变量会破样式 | 只删 `.dark` 令牌块与 `dark:` 工具类，不动组件亮色默认变量；grep + 浏览器双验收 |
| 术语替换误伤后端返回的展示字段 | 只改前端展示层文案；全仓 grep 中文旧词逐处核对，API 契约零变更 |
| 字号统一后个别密集布局（连接页信息卡）溢出 | 回环时逐页检查溢出；溢出处优先减信息密度而非缩字号 |

## 验证策略

- 前端组件测试先行/随行：PageHeader、Markdown 层级、SkillCard 徽章数、Vault 导航单轨与详情 overlay 钩子、术语文案
- 硬编码清零用 grep 验收：`indigo-`、`text-[10px]`、`dark:`、`.dark{`、旧术语词
- 浏览器回环 8 场景（详见 tasks T9）；API 用 Invoke-WebRequest 二次核实（P1 无契约变更，仅确认接口未动）
- 双侧 vitest 全绿（基线：后端 520 / 前端 124，只增不减）、双侧 tsc 0 错、tsup + vite build 通过

产品仍在打磨、界面还会改版，因此按「改版后返工代价」分两批，**不要现在一次性做完**：

- **等产品信息架构定稿再做（强耦合，改版要返工）**：T1 卡片图与 T2 卡片标签、T3 README 首屏素材与文档站界面截图、

## T1 卡片图规格登记与素材归位（0.5 天）

- 登记卡片图规格：1280×640、宽高比 2:1、PNG 或 JPG、单文件 ≤ 1 MB；替代文本一句话、中性
- 素材来源：复用与仓库社交预览同源的那张图，**不新设计**；由维护者导出后放入两处静态资源目录（公开站点、本机界面各一份，避免构建期跨目录依赖）
- 在 `设计文档/changes/add-launch-seo/` 内记录最终文件名与两类产物中的相对路径（不写本机绝对路径）
- 验收：
  - 图片尺寸恰为 1280×640，格式与体积符合登记值
  - 两张副本内容一致，路径可被两条构建原样复制到产物根目录
  - 替代文本不含个人称谓、用户名、本机路径、客户或项目信息
  - 未提供图片时本任务保持未完成，且阻断 T2 的发布验收（不允许带 404 的卡片上线）

## T2 社交卡片元数据（公开站点完整，本机界面只做最小集，0.5 天）

- 公开站点：在站点配置的页面头部声明卡片图（绝对地址，含站点子路径）、宽 1280 / 高 640、替代文本、
  卡片类型 `summary_large_image`、卡片专用图与标题/描述；保留并复用现有通用社交标题与描述
- 本机界面：`web/index.html` 只补页面标题、描述与卡片标签，图片地址指向随构建复制的静态资源；
  **不加** `sitemap.xml`、`robots.txt`、`canonical`、`og:url`、结构化数据（D9：爬虫到不了本机，加了也没有效果）
- 两份文档的站点级描述保持同一口径（一处维护语义、多处引用，避免文案漂移）
- 验收：
  - 公开站点构建后，入口 HTML 的头部**静态可见**卡片图、宽高、替代文本、卡片类型、标题、描述
  - 本机界面构建后，入口 HTML 可见标题、描述与卡片标签，且产物中不存在 sitemap / robots / canonical / og:url
  - 卡片图地址为绝对 URL 且含子路径；不出现相对路径或本机地址
  - 无页面级描述时回落到站点级描述，不出现空值
  - 不新增任何第三方脚本（对照 R7.1）

## T3 README 首屏素材与界面可发现性（0.5 天，GIF 可后补）

- `README.md` 与 `README.zh-CN.md` 在标题与徽章组之后、第一段正文之前插入首屏素材
- 优先 GIF；GIF 未就绪时用真实界面静态截图占位（D4），两份 README 用同一素材、同一 alt 口径
- 素材入库到仓库内（如 `docs/public/` 或既有图片目录），不外链第三方图床
- 文档站「快速开始」页插入同一张真实界面截图（能看出分类、数量、状态一屏可见的资产全貌），
  并在图下写一句启动指引：启动后在本机浏览器打开对应地址查看自己的资产（R9.1）
- 验收：
  - 两份 README 首屏均有图且链接可解析，无坏链、无本机绝对路径
  - 文档站快速开始页有同口径界面截图 + 启动指引；截图不是设计稿或合成图
  - 单文件 ≤ 5 MB；超限则压缩或退回静态图
  - 素材为真实界面截图/录屏，不用设计稿或合成图冒充
  - 抽查浅色/深色背景下的可读性，图片宽度不撑破版面

## T4 站点地图生成（0.5 天）

- 用站点构建器自带的站点地图能力生成，不在仓库里手工维护页面清单
- 覆盖 5 个公开页：首页、入门指南、支持的工具、数据与隐私、常见问题；地址为绝对 URL 且含站点子路径
- 排除：错误页、带查询参数或锚点的地址、本机地址、仅本机可访问的界面路由
- 生成失败必须让构建失败（不得静默产出缺件产物）
- 验收：
  - 生产构建后产物根目录存在 `sitemap.xml`，条目数与公开页数一致（本期 5 条）
  - 逐条访问均可打开，无 404、无跨页跳转
  - 新增一个公开页后重建，地图自动多出该页
  - 站点主机或子路径变更后，地图地址随之更新，无需手改

## T5 抓取指引（0.5 天）

- 在公开站点的静态资源目录新增 `robots.txt`，随构建复制到产物根目录
- 内容只做两件事：对所有抓取方放开站点；用一行指令指向站点地图的绝对地址
- 不写资源级屏蔽、不写整站禁止、不出现第三方域名
- 验收：
  - 产物根目录存在 `robots.txt`，抓取指引里的地图地址与实际地图位置逐字符一致
  - 抓取方访问公开页时，样式、脚本、图片均未被拦截
  - 本机界面**不产出** `robots.txt`（D9：爬虫到不了本机，产出只会误导）

## T6 构建产物验收与零统计守门（0.5 天）

- 两条流水线各跑一次生产构建：公开站点核对 `sitemap.xml` / `robots.txt` 与入口 HTML 头部卡片标签；
  本机界面只核对标题、描述、卡片标签，并确认产物内没有 sitemap / robots / canonical / og:url
- 对仓库与两份产物做统计脚本扫描：脚本引用、上报地址、内联片段、图片像素、依赖清单五类都查
- 手工对照 `specs/p0.spec.md` 全部 Scenario，把结论记到本文件「验收记录」
- 验收：
  - 两条构建均成功：公开站点三件套在产物中可见；本机界面零维护元数据可见且无索引类文件（R6.1 / R6.2）
  - 统计脚本命中数 0（R7.1 / R7.3）
  - 卡片图尺寸与体积复核通过；缺图或尺寸不符时发布不通过
  - `node scripts/privacy-check.mjs` 退出码 0
  - 文档中不出现真实用户名、本机绝对路径、公司或客户信息，示例域名均为通用占位
